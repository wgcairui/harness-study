# 评审评分表

| 维度 | 问题 | 得分 (0-2) | 备注 |
| --- | --- | --- | --- |
| 正确性 | 实现出来的行为是否符合目标功能？ |  |  |
| 验证 | 要求的检查真的跑过并留下证据了吗？ |  |  |
| 范围纪律 | 会话是否保持在选定功能范围内？ |  |  |
| 可靠性 | 结果能否在重启/重跑后继续工作？ |  |  |
| 可维护性 | 代码和文档是否清楚到能交给下一轮会话？ |  |  |
| 交接准备度 | 新会话能否只靠仓库内文件继续推进？ |  |  |

## 结论

- Accept — 达标
- Revise — 需修补后重审
- Block — 有根本性问题，先解决
